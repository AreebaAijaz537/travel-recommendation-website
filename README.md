# Travel Explorer

Travel Explorer is a simple travel recommendation website created as a web development project.

## Features

- Home, About Us, and Contact Us pages
- Navigation bar
- Travel search feature
- Beach recommendations
- Temple recommendations
- Country-based recommendations
- Responsive layout
- Contact form

## GitHub Pages

This project is designed to run as a static website using GitHub Pages.


Search test terms for the assignment: beach, temple, country. Each search displays the matching recommendation section with two images.
